# Try VOLTA

Open the app and choose **Read the on-chain example** for a wallet-free read of the recorded exhibition procedure. The app checks deployed source identity, reads the book from finalized state and loads its accepted review. Inspect the pairwise evidence, reorder the stones locally, and export JSON. Changing a local order never changes a published book.

In Practice, move S5 above S4. The arch loses its keystone and the interface identifies S4 → S5. Restore order to return the arch to its coherent form. Practice relationships are authored offline examples, not inferred results.

For your own record, select On chain, edit the title, excerpt and steps, start a browser wallet or temporary Studio session, then seal, assess and publish. A temporary key is lost on reload, so complete its signing workflow before refreshing. Export the public reference to retain access to readbacks.
